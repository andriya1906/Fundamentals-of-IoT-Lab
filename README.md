# Fundamentals of IoT Lab

This repository contains the Embedded C programs and laboratory experiments completed as part of the Fundamentals of IoT (25CS2741) course at Shiv Nadar University, Chennai.

## Course Details

* **Course:** Fundamentals of IoT (25CS2741)
* **University:** Shiv Nadar University, Chennai
* **Programming Language:** Embedded C

### AT89S52 / 8051 Experiments

* **Microcontroller:** AT89S52 (8051)
* **Development Environment:** Keil µVision
* **Programming Tool:** ProgISP

### STM32 Experiments

* **Microcontroller:** STM32F103C8T6
* **Development Board:** STM32F103C8T6 Blue Pill
* **Development Environment:** STM32CubeMX and Keil MDK
* **Programming/Debugging Tool:** ST-Link
* **Serial Terminal:** PuTTY
* **Communication Interface:** USB-to-TTL Converter
* **Library:** STM32 HAL
